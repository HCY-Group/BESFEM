# Contributing to BESFEM

Thank you for your interest in contributing to BESFEM! We welcome community involement and appreciate your help in improving our project.  

## Workflow: How to Help

We use GitHub to organize our work. When making updates, we try to follow the procedure below. 

### A. Before You Begin

1. Create an [issue](https://guides.github.com/features/issues/) where new proposals can be discussed before any coding is done. 
2. Create a [branch](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-a-branch-for-an-issue) for an issue of this repo where all changes will be made.
