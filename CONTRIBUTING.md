# Contributing to BESFEM

Thank you for your interest in contributing to BESFEM! We welcome community involement and appreciate your help in improving our project. 

## Workflow: How to Help

We use GitHub to organize our work. When making updates, we try to follow the procedure below. 

### A. Before You Begin

1. Create an [issue](https://guides.github.com/features/issues/) where new proposals can be discussed before any coding is done. 
2. Create a [branch](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-a-branch-for-an-issue) for an issue of this repo where all changes will be made. 

### B. Writing Your Code

3. BEFEM is developed in C++, while plotting is done in Python. 
4. Commit your changes to your branch with useful, descriptive commit messages. Keep in mind that these are publically visible. 

### C. Merge Your Changes with BESFEM

5. Test your code and ensure doxygen comments have been added!
6. When you think your code is finished, create a [pull request](https://docs.github.com/en/pull-requests/reference/pull-requests) on [BESFEM's GitHub Page](https://github.com/HCY-Group/BESFEM).
7. Once a pull request has been created, it will be reviewed by another member of the community. When everything is finished, someone with the right permissions will merge your changes in BESFEM's main repository.
